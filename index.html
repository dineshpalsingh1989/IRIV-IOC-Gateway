MQTT

Publish values to a broker on your LAN and receive output commands.

Values publish at QoS 0. With TLS and a CA certificate, the controller checks the broker's certificate against it, using its clock (set it from the installer); the certificate must list the broker address above as a DNS name, even when it is an IP address. With TLS and no certificate, the link is encrypted but the broker is not checked.

Default topicsfactory/line01/ioc01/di0/state

Every pin and RS485 point publishes under the base topic unless you key in your own topic in the map below.

Ethernet

The controller's address on your LAN.

Lost the address?

Hold the USER button while powering up: the controller starts on 192.168.4.1 for a laptop plugged in directly.

Web page

The controller shows this dashboard, with live values, at http://its-IP-address/.

Anyone on the LAN can look at the page. Saving settings, updating the firmware and testing outputs from it need this password. Send it over USB once; on the controller's own page, leave it empty to keep the saved one.

RS485 · Modbus RTU master

Polls devices on the RS485 bus and republishes their values to the LAN.

Wiring

A, B and G on terminal 1 · max 500 kbps · turn on the 120 Ω termination switch only at the two ends of the bus.

    Install the firmware

    Looking for the latest firmware…

    Plug in USB-C and click Install. It looks at what is on the controller and does the right thing: an older gateway is updated straight away; an up-to-date one is only checked; other firmware is replaced after you agree; a new or empty controller shows up as a drive called RP2350 (see below). After every install it reconnects, runs the full check (Ethernet chip, clock, flash, temperature) and shows the result, with the IP address, in the log. Nothing to download.

    New controller, or install by hand
                  
    
                    
    A new or empty controller, or one with other firmware, needs install mode once. The Install button does this when it can; otherwise hold BOOT, tap RESET, release BOOT (pinholes on the front, use a paperclip). A drive called RP2350 appears: click Write firmware to the RP2350 drive and pick it. The installer then reconnects and logs the result above.
